# Codriod local workspace

The launcher opens a native Jetpack Compose home screen. Projects are stored in the app-private files directory under workspaces. Project names never become executable paths. Editor, filesystem, and preview operations use ProjectStore, which rejects paths outside a project, hides its metadata, limits text files to 256 KiB, avoids following symlinks in the explorer, and replaces files via a temporary file.

The Web starter includes HTML, CSS, and JavaScript. The Compose editor supports saved per-project tabs, text editing, syntax-color hints, project search, file and folder creation, rename and delete, autosave, undo and redo. The bundled terminal runs the installed Android /system/bin/sh with the selected project as its starting directory. Only .sh files are executed by Run. This shell is Android's own shell, not Linux, Bash, Node.js, Python, Java, or a general-purpose package environment.

The preview is a responsive browser-like workspace backed by a real Android WebView. Its address bar navigates project HTML paths, its tabs switch between project HTML files, and Mobile, Tablet and PC controls render at their selected CSS viewport sizes. The Dev panel exposes the WebView JavaScript console, current page/viewport details and project HTML pages. Project-owned HTML, CSS, JavaScript, JSON, images and fonts are served through an intercepted HTTPS origin. Other hosts and local device file access are blocked; there is no JavaScript bridge to application code. This is a local-file WebView, not an HTTP or Node.js development server, and its Dev panel is not a full Chromium inspector.

The Source Control screen uses JGit for local repository initialization, status, staged and unstaged text diffs, stage/unstage, commits, history, and local branches. Codriod's project metadata is kept out of Git, and `.git` internals are hidden from the file explorer. Branch checkout is refused while the worktree has changes. The Remote tab adds the user's own GitHub sign-in (an SSH key created on the phone), the origin remote, fetch, pull and push, and Home can clone repositories; see [GitHub login](github-login.md). Merge conflict resolution is not included.

VS Code-inspired colors: primary blue #007ACC; Dark+ editor #1E1E1E, sidebar #252526, text #D4D4D4; Light+ editor #FFFFFF, sidebar #F3F3F3, text #333333. Theme selection is stored in workspace preferences. The editor and terminal include horizontally scrollable coding-key strips for brackets, quotes, shell symbols, Tab, Esc, Ctrl, arrows, cursor movement, copy and paste. Code highlighting is a small visual aid, not a full language parser or LSP.

SSH, Python/Node/Java installation, imported or shared folders, file picker, full-text binary search, multi-cursor, full undo history and a network-enabled preview are outside this implementation. The existing terminal activity remains available from the Home screen.
